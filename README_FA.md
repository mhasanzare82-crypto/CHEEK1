# CHEEK1 Android — نسخه اولیه

این پروژه یک برنامه اندرویدی مستقل و آفلاین برای مدیریت چک‌لیست است.

## امکانات پیاده‌سازی‌شده
- ایجاد، تغییر نام و حذف چک‌لیست
- افزودن، ویرایش، حذف و علامت‌گذاری موارد
- ورود XLSX: ستون اول هر ردیف غیرخالی از شیت اول به یک مورد تبدیل می‌شود
- خروجی XLSX برای چک‌لیست انتخاب‌شده (با تولید مستقیم فایل Open XML)
- خروجی و ورود فایل پشتیبان JSON
- بازیابی با پشتیبانی اولیه از نام‌های ساختاری رایج قدیمی (`checklists`، `tasks`، `title`، `completed`)
- تنظیم اندازه فونت
- بارگذاری فونت TTF/OTF
- قفل زیست‌سنجی/اعتبارنامه دستگاه
- ذخیره‌سازی محلی در فضای خصوصی برنامه؛ بدون مجوز اینترنت

## ساخت APK
1. Android Studio را نصب کنید.
2. پوشه پروژه را باز کنید.
3. اجازه دهید Gradle وابستگی‌ها را دریافت کند (فقط برای ساخت؛ خود برنامه مجوز اینترنت ندارد).
4. از منوی Build گزینه Build Bundle(s) / APK(s) > Build APK(s) را انتخاب کنید.
5. خروجی معمولاً در `app/build/outputs/apk/debug/app-debug.apk` قرار می‌گیرد.

## نکات مهم پیش از انتشار/استفاده جدی
- این محیط فاقد Android SDK و Gradle اجرایی است؛ بنابراین APK در اینجا کامپایل و روی دستگاه آزمایش نشده است. فایل تحویلی، سورس پروژه است. ساخت نخستین APK به Android Studio و دریافت وابستگی‌های Gradle نیاز دارد.
- برای سازگاری قطعی با نسخه‌های پشتیبان قدیمی، باید یک یا چند نمونه واقعی از فایل‌های پشتیبان قدیمی آزمایش شود. در حال حاضر مهاجرت ساختارهای JSON متداول پشتیبانی شده است.
- ورود اکسل فعلاً از ستون اول شیت اول استفاده می‌کند و سطر عنوان را نیز مثل بقیه ردیف‌ها وارد می‌کند؛ در صورت نیاز می‌توان تشخیص عنوان یا انتخاب ستون/شیت را اضافه کرد.
- فایل‌های پشتیبان را در محل امن نگه دارید. حذف برنامه ممکن است داده‌های داخلی آن را پاک کند.
